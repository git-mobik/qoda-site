How a task flows

  1. 1

    Describe the task

    “Add a dark mode toggle and update the tests.” Qoda reads the workspace first.

  2. 2

    Agent works locally

    It edits files and runs commands in your project — each step checkpointed, each command visible.

  3. 3

    You stay in control

    Permission prompts, access levels and an internet switch decide what the agent may touch.

  4. 4

    Review and ship

    Diff the changes, revert anything, keep the parts you like.

Built to be supervised

Access levels

Read-only, ask-before-write, or full access. Switch any time; sensitive paths stay blocked.

Internet gate

One chip turns network tools off. With it off, the agent asks before reaching out.

No keys to leak

No API credential is stored — Qoda uses the browser session you signed in with.

Questions

Do I need an API key?

No. Qoda drives the DeepSeek web session you already have, so there is nothing to paste and nothing to bill per token.

Where does my code go?

Your files stay on your machine. Only the context the agent sends to the chat leaves your computer — the same content you would type yourself.

Can I undo the agent's edits?

Yes. Every write is checkpointed, and the diff view reverts either a single file or all changes from a step.

Is it open source?

The repository is private for now. This page is an unlisted preview — please don't share the link.
